Reminder: this chart does NOT run database migrations. Before the first deploy to a new
environment, run matching-scoring-service/scripts/migrate.ts (and validate-schema.ts) against
the target database out-of-band, then scripts/backfill-matching-scoring-service.ts from the
monolith - see matching-scoring-service/README.md and MIGRATION_RUNBOOK.md.

This service has no gateway route and no user-facing HTTP surface - its only caller is the
monolith's own src/reasoningServiceShadow.ts, gated behind SHADOW_REASONING_ENABLED (default off).
Set MATCHING_REASONING_SERVICE_URL on the monolith's own deployment to point at this service
before enabling that flag.
